## 1. Resumen del proyecto
- **Nombre:** spanishstore
- **Objetivo:** Crear un **tema de Shopify** personalizado. Se desarrolla en local y después se sube a la tienda.
- **Tienda:** "The Spanish Store". Vende comida española (embutidos, marisco, quesos, paella, despensa, snacks y dulces, regalos, bebidas). Los textos están en **inglés** y el mercado es **Canadá** (precios en CAD; envío gratis en todo Canadá a partir de CAD $300). Corregido el 2026-10-07: antes ponía EE. UU. por error.
- **Estado actual:** Topbar, cabecera (header + menú), **hero**, **barra de ventajas**, **tarjetas de categorías** **carrusel de productos (Best sellers)**, **galería de vídeos de la comunidad**, **constructor de packs**, **banner de quesos**, **rejilla "More to discover"**, **banner dividido de charcutería**, **carrusel Seafood**, **collage Pantry/Snacks/Beverages**, **banner de paella**, **carrusel Charcuterie**, **testimonios**, **recetas (blog)**, **banner "Give a taste of Spain"** y **barra de cuenta atrás**, más el **footer** (en todas las páginas) y la **página de tienda/colección** (filtros, orden, rejilla), implementados según los diseños. Theme Check revisa 58 archivos y no encuentra errores. Verificado con una vista previa estática. El usuario ya creó su tienda de desarrollo, pero todavía no se ha ejecutado `theme dev` (falta el nombre `.myshopify.com`).

## 2. Stack y tecnologías
- **Plataforma:** Shopify (Online Store 2.0: plantillas JSON, secciones y bloques)
- **Lenguajes del tema:** Liquid, HTML, CSS, JavaScript
- **Tema base:** Skeleton theme v1.0.0 (https://github.com/Shopify/skeleton-theme). Es mínimo y está pensado para construir un diseño propio.

**Importante:** el Liquid se renderiza siempre en los servidores de Shopify. "Trabajar en local" significa que los archivos están en el PC, pero la vista previa necesita conexión a una tienda (aunque sea de desarrollo). El primer comando que se conecte a la tienda abre el navegador para iniciar sesión, y ese paso lo hace el usuario.

## 8. Notas y contexto adicional
### Cómo crear la tienda de desarrollo (verificado 2026-10-07 en shopify.dev)
- Es **gratis**. Se gestiona desde el **Dev Dashboard**: https://dev.shopify.com/dashboard/
- **Por la web:** Dev Dashboard → **Stores** → crear tienda → tipo **Dev** → nombre (será `<nombre>.myshopify.com`) → plan → recomendado: generar datos de prueba.
- **Por la CLI:** `shopify store create dev --demo-data --country ES` (pide iniciar sesión en el navegador).
- **Limitaciones:** la tienda siempre tiene contraseña (no se puede quitar) y solo admite pedidos de prueba (Bogus Gateway). `theme dev` puede pedir esa contraseña de la tienda, que está en Tienda online → Preferencias. Para cambiarla: panel de la tienda → Tienda online → Preferencias → Protección con contraseña → escribir la nueva → Guardar. Se puede pasar a la CLI con `--store-password`.
- La cuenta la crea el **usuario**. Claude no puede crear cuentas ni introducir contraseñas.

### Cómo comprobar el diseño sin tienda conectada
- Como el Liquid no se puede renderizar en local, se hizo un HTML estático con el CSS y el JS reales de las secciones. Se sirvió con `python -m http.server` y se capturó con Edge en modo headless (`--headless=new --screenshot`) y con el navegador integrado en modo móvil.
- Ojo: Edge headless tiene un ancho mínimo de ventana de unos 500 px, así que las capturas a 375 px salen recortadas. Para móvil, usar la emulación del navegador.

### Otras notas
- Al instalar la CLI, npm muestra un aviso de que la dependencia `boolean@3.2.0` está obsoleta. No afecta al funcionamiento.
